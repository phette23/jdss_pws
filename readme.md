# Create 1Password Items from CSV

Create a series of passwords from a CSV. This is for JSTOR Digital Stewardship where there are different login pages for Tier 1 versus Tiers 2 and 3, so we take a CSV with `org,tier,email` columns then create a 1Password item for each row in the "SCELC" password VAULT.

https://www.1password.dev/cli/item-create
